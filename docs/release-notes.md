物语（Monogatari）首个独立签名正式版本。

- 播放按优质（1080zyk4）、暴风、量子顺序自动尝试，无需选择来源。
- 更新直接读取本项目 GitHub Releases，Android 按设备架构下载 APK，Windows 便携版可自动替换并重启。
- iOS 检测新版本后打开 IPA 下载地址，下载后自行签名安装。
- 修复切集与续播竞态、下载错误页识别、暂停恢复及历史同步中的剧集身份问题。

Android 使用物语独立正式签名，和之前的调试包签名不同。首次从调试包迁移时请先备份数据，再安装正式版；此后的正式版可以覆盖更新。

Windows ZIP 包须完整解压后运行 Monogatari.exe。iOS IPA 未使用 Apple 分发证书签名，需要自行签名。

弹幕依赖中转服务；当前中转接口不可用，待服务端恢复。
