物语（Monogatari）2.4.5

- 详情页的播放按钮会从上次看到的那一集继续，旁边新增选集，可以直接挑一集开始播放。
- 播放器新增字幕与音轨选择，支持加载本地外挂字幕。
- 可以手动把单集标记为看过或没看过，也可以一次标记到某一集；已在追番且开启同步时会同步到 Bangumi。
- 新增海报分享，生成带封面、评分和二维码的番剧海报，可分享或保存到相册。
- 每部番会记住自己的倍速、弹幕开关、字幕和音轨，下次打开自动沿用。
- 使用移动网络播放时会先提醒，播放中从 Wi-Fi 切到移动网络也会提示，可在播放设置里关闭。
- 可以给番剧写一句备注，在详情页和追番列表里显示。
- 时间表新增新番速览，左右滑动卡片快速把本季新番加入想看、在看或跳过，支持撤销。
