物语（Monogatari）2.4.0：蜜柑 RSS 订阅与磁力播放。

- 支持按番剧订阅蜜柑字幕组，在在线播放与 RSS 播放间切换，并记住每部番的选择、字幕组和观看进度。
- 默认仅播放：按播放位置缓冲，退出后清理临时数据；播放设置可开启“边下边播并保留文件”，手动下载始终保留。
- 新增磁力任务列表，支持文件选择、暂停、继续、删除和缓存播放。RSS 不可用时可按设置自动尝试在线播放，保留原有 RSS 偏好。
- 优化缓存订阅启动、种子元数据获取、首段与拖动后的分片调度；网络、校验和文件读取在后台执行，限制并发与内存使用。
- 改善在线播放准备速度及剧集身份匹配，避免目录顺序变化导致续播到错误集数。

普通安卓手机优先下载 Monogatari-Android-arm64.apk；旧款 32 位设备使用 armv7，x64 用于对应架构设备或模拟器。正式版可覆盖更新。

Windows ZIP 请完整解压后运行 Monogatari.exe。iOS IPA 需自行签名安装，应用内检测到更新后会打开下载地址。

磁力播放速度取决于资源做种数量和当前网络；移动端默认仅允许 Wi-Fi 下载。弹幕密钥本次未调整。
